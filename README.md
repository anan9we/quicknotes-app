# QuickNotes

QuickNotes is a simple web-based note-taking application that allows users to create, organize, search, and delete notes. Notes can be assigned to Personal, Work, or Study categories, and they are saved in the browser so they remain available after refreshing the page.

## Features

- Add notes with a category
- Personal, Work, and Study categories
- Delete individual notes
- Search notes in real time
- Validate notes to prevent empty notes and notes over 200 characters
- Display the number of saved notes
- Save notes using localStorage
- Restore notes after refreshing the page
- Responsive layout for smaller screens

## How to Run Locally

1. Clone or download the QuickNotes repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding and managing your notes.

No additional software or dependencies are required.
